# AI Agent Prompts

Use these prompt starters for future AI-assisted troubleshooting features.

## Log Summary

Summarize this launch log for a macOS user. Identify the likely failure point, the compatibility backend involved, and the next safe troubleshooting steps.

## Compatibility Recipe Draft

Create a concise compatibility recipe from these notes. Include backend, bottle or prefix details, launch arguments, environment variables, known issues, and tested game status.

## Crash Triage

Review this stderr output and classify the issue as missing dependency, graphics translation, filesystem path, permissions, launcher configuration, or unknown. Explain what evidence supports the classification.
